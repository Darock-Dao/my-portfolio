# Responsive Design Skill

When modifying UI, verify the implementation at mobile, tablet, and desktop
breakpoints.

## Review

- Check for horizontal scrolling.
- Check that text remains readable.
- Check that images scale appropriately.
- Check that navigation remains usable.
- Check that buttons and interactive elements remain accessible.
- Check that columns stack appropriately on narrow screens.
- Check for overlapping or clipped content.
- Check that spacing remains visually balanced.

## Validation

Use the browser's responsive/device emulation tools to inspect the page at
representative viewport sizes.

At minimum, verify:

- Mobile: ~375px
- Tablet: ~768px
- Desktop: ~1440px
