# Project Rules

## Project
This is my personal portfolio website showcasing my background, work experience,
projects, technical skills, and professional/social links.

## Technology
- React 19.1.1
- React DOM 19.1.1
- Bootstrap 5.3.8
- Vite 7.1.12


## Coding conventions
- Follow existing patterns and conventions before introducing new abstractions.
- Prefer small, focused changes.
- Do not refactor unrelated code.
- Preserve existing functionality unless explicitly required to change it.
- Reuse existing components and styles when appropriate.
- Keep components focused and avoid unnecessary complexity.
- Prefer responsive designs that work across desktop, tablet, and mobile.

## Responsive Design
- The portfolio must remain usable and visually coherent across desktop,
  tablet, and mobile screen sizes.
- New UI must be responsive by default.
- Do not introduce fixed dimensions or layouts that cause horizontal
  scrolling or content overflow on smaller screens.
- Preserve readable typography, spacing, and touch-friendly controls
  on mobile.

## Safety
- Do not delete files without approval.
- Do not introduce new dependencies without justification.
- Do not modify configuration unrelated to the requested feature.
- Do not expose private information, credentials, API keys, or secrets.

## Validation
- Build the project after implementation.
- Run relevant tests and linting when available.
- Verify responsive behavior when making UI changes.
- Report build, test, and lint results.
